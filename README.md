# Evently — афиша мероприятий

Статическая главная страница веб-приложения для поиска городских мероприятий:
концертов, кинопоказов, выставок, лекций, фестивалей и театральных постановок.

## Для кого этот проект

Для жителей города, которым нужно быстро найти интересный досуг: пользователь
открывает афишу, смотрит карточки ближайших событий и с помощью фильтра
подбирает мероприятие по месту, типу и дате.

## Что уже готово

Это первая лабораторная работа, поэтому страница пока статическая: данные о
мероприятиях находятся прямо в HTML, форма не выполняет поиск, карточки не
загружаются с сервера.

## Основные блоки страницы

- **Шапка** — название проекта «Evently», навигация по разделам («Главная»,
  «Мероприятия», «О проекте») и иконка-ссылка на форму поиска.
- **Hero** — главный заголовок «Афиша мероприятий» и короткое описание проекта.
- **Форма поиска** — три поля (место, тип мероприятия, дата) и кнопка «Найти».
- **Ближайшие мероприятия** — сетка из шести карточек. У каждой карточки
  изображение, название, дата, место, тип и краткое описание.
- **«Как выбрать мероприятие?»** — подсказка по использованию фильтра.
- **Подвал** — название проекта и информация о нём.

## Как открыть

1. Скачай или клонируй репозиторий.
2. Открой файл `index.html` в браузере.

## Использованные технологии

- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `section`,
  `article`, `footer`).
- **CSS3** — отдельный файл стилей, CSS Grid для сетки карточек, Flexbox для
  шапки, навигации и формы, медиазапросы для адаптивности.
- **SVG** — иконка поиска в шапке.

## Адаптивность

Страница проверена при ширине окна **360, 768 и 1280 пикселей**:

- до 600px — карточки в одну колонку, форма и шапка в столбик;
- 601–900px — карточки в две колонки;
- от 901px — карточки в три колонки.

Горизонтальная прокрутка не появляется, изображения не выходят за пределы
карточек.

## Доступность

- У всех полей формы есть видимая подпись `label`, связанная через `for` и `id`.
- У содержательных изображений заполнен `alt`, у декоративной иконки поиска
  стоит `aria-hidden="true"`.
- Видимая рамка фокуса сохранена у ссылок, кнопок и полей ввода.
- По странице можно перемещаться с клавиатуры клавишей **Tab**.
